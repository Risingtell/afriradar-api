How it works

Four steps, all on chain

  1. Price

    Your request comes back 402 Payment Required with the price, the USDC mint and the payee. No account, no key.

  2. Sign

    For raw data your wallet signs a USDC transfer. For a question it signs a deposit into a Solana Foundation payment channel, capped at $0.05.

  3. Settle

    AfriRadar's own facilitator checks the payment and settles it on Solana. For a question it claims only the itemized bill; the channel refunds the rest.

  4. Deliver

    The data arrives with its transaction in the PAYMENT-RESPONSE header. An error is never charged, and a paid but unconfirmed request is checked on chain before the reply.

Proof runs on Solana devnet

Try to overcharge a buyer

A question locks a $0.05 deposit in a Solana Foundation payment channel. Press the button and our server signs a claim for one micro-USDC more than the deposit, the way a dishonest server would. A Solana validator runs it with the buyer's real channel-open transaction. It is a simulation, so nothing is sent and nothing is spent.

Build with it

CLI, SDK and MCP

Terminal

npx afriradar wallet --new
# fund it at faucet.circle.com (Solana Devnet)
npx afriradar top money-market --limit 5
npx afriradar ask "Which dollar fund pays the most?"
npx afriradar verify

Code

import { createAfriRadar, loadSigner } from "afriradar";

const api = createAfriRadar({ signer: await loadSigner(), budget: 0.1 });
const { data, receipt } = await api.top("money-market", { limit: 3 });
console.log(data.funds[0].name, receipt.explorer);

Boundary

What this is, and is not

Live now

  • Regulator fund data for every Nigerian fund (weekly since January 2025) and every Kenyan unit trust scheme (quarterly since December 2023), refreshed daily from afriradar.com.
  • Real x402 payments on Solana devnet: fixed-price transfers and capped payment channels.
  • Our own facilitator, a public ledger, and a chain verifier anyone can run, in a terminal or in this page.
  • A live proof that Solana enforces the analyst's cap, and an hourly end-to-end payment check.
  • A hosted MCP server whose paid tools charge over x402.

Not yet

  • Mainnet. Payments use free devnet USDC while the service is tested.
  • Advice. This is data. The analyst never tells anyone to buy or sell.
  • Markets beyond Nigeria and Kenya. Each is added once its regulator's file can be verified.
